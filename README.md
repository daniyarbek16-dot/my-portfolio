# Интерактивное портфолио художника 🎨

Это мой личный сайт в ввиде портфолио художника, написанный с нуля на чистом HTML, CSS и JavaScript. 

## 🚀 Главные фишки проекта
* **Боковая панель навигации** в стиле браузера Opera.
* **Адаптивность**: на телефонах панель аккуратно перестраивается вниз.
* **Динамическая загрузка**: при клике на разделы («Затмение», «Синее пламя», «Молния») контент мгновенно перестраивается без перезагрузки страницы благодаря JavaScript и JSON.
* **Визуал**: 3D-эффекты карточек.

## 🛠️ Технологии
* HTML5 (Семантическая разметка)
* CSS3 (Flexbox, Grid, 3D-трансформации, анимации)
* JavaScript (Vanilla JS, Fetch API, DOM-манипуляции)
